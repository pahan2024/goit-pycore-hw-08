# Консольний бот-помічник (Адресна книга)

Цей проєкт є консольним застосунком для керування контактами та їхніми днями народження. У цій версії додано функціонал **автоматичного збереження та відновлення даних** з використанням протоколу `pickle`. При закритті програми всі зміни записуються на диск, а при наступному запуску — відновлюються, що запобігає втраті даних між сеансами.

## Основний функціонал

- 💾 **Автозбереження та автозавантаження**: Повна інтеграція з `pickle`. Дані автоматично зчитуються при старті та записуються у файл `addressbook.pkl` при виході.
- 👤 **Керування контактами**: Додавання, зміна номерів телефонів, перегляд усіх збережених записів.
- 🎂 **Робота з днями народження**: Додавання дат народження, перегляд дат конкретних контактів та автоматичний розрахунок списку найближчих іменинників на наступні 7 днів (із урахуванням перенесення вихідних днів на понеділок).
- 🛠️ **Обробка помилок**: Використання декоратора `@input_error` для перехоплення некоректного введення аргументів та інформування користувача у зручному вигляді.

## Список доступних команд

- `hello` — привітатися з ботом.
- `add [ім'я] [телефон]` — додати новий контакт або новий номер до існуючого контакту (телефон має складатися рівно з 10 цифр).
- `change [ім'я] [старий_телефон] [новий_телефон]` — змінити існуючий номер телефона.
- `phone [ім'я]` — показати всі номери телефонів для вказаного контакту.
- `all` — вивести всю адресну книгу на екран.
- `add-birthday [ім'я] [дата_народження]` — додати дату народження у форматі `ДД.ММ.РРРР`.
- `show-birthday [ім'я]` — показати дату народження контакту.
- `birthdays` — показати список контактів, у яких день народження протягом найближчих 7 днів.
- `close` або `exit` — зберегти дані у файл `addressbook.pkl` та вийти з програми.

## Як запустити проєкт

1. Переконайтеся, що у вас встановлено Python 3.
2. Перейдіть до папки проєкту в терміналі.
3. Запустіть головний файл програми:
   ```bash
   python main.py
   ```

## Структура проєкту

- `main.py` — головний файл застосунку, що містить логіку користувацького інтерфейсу (парсер команд та основний цикл), а також функції серіалізації `save_data` та `load_data`.
- `.gitignore` — файл конфігурації Git, який виключає локальну базу даних `addressbook.pkl` та кеш Python (`__pycache__`) з відстеження репозиторієм.
